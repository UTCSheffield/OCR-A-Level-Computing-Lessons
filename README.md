# OCR-A-Level-Computing-Lessons
OCR-A-Level-Computing-Lesson slideshows with real code

## Setup

Install the base Python environment with:

```bash
pip install -r requirements.txt
```

The Manim slideshow notebook also needs Manim plus native Linux libraries. On Ubuntu/Debian, install them first with:

```bash
sudo apt-get install libcairo2-dev libpango1.0-dev ffmpeg pkg-config
pip install manim
```
